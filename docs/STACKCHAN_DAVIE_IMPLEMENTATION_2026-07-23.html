Implementation report · 2026-07-23

Official Stack-chan.
Local Davie.

以官方 1.4.3 开源固件为主体，通过独立 Gateway 接入本地 ASR、Davie、TTS 和视觉能力。本文记录已实现内容、真实证据、恢复路径及尚未伪造通过的物理验收项。

最终架构

Stack-chan 设备

保留官方屏幕、表情、舵机、触摸、摄像头、双麦克风、扬声器、配网、OTA、Xiaozhi WebSocket/Opus 与 MCP。

Local Gateway

负责协议转换、端点判断、generation-safe 打断、相机会话绑定、认证和运行状态，不承载模型权重。

NVIDIA Media

Fun-ASR 处理语音输入，CosyVoice3 处理语音输出。Gateway 只传输标准 WAV/PCM/Opus 数据。

Davie

继续负责人格、记忆、知识库、工具、任务编排和多模态理解；设备通过稳定 session key 与 session id 延续上下文。

构建与部署

固件

cp firmware/sdkconfig.defaults.davie.example firmware/sdkconfig.defaults.local
# Edit only local endpoint values. Provision Wi-Fi through the device UI.
source /path/to/esp-idf-v5.5.4/export.sh
cd firmware
python3 fetch_repos.py
idf.py build
idf.py -p <SERIAL_PORT> flash

Gateway

cd integrations/davie-gateway
uv sync --dev
uv run pytest -q
uv build
# Install the wheel on a Linux host and use deploy/stackchan-davie-gateway.service.

恢复路径

NAS 已保存原厂 1.4.4 完整 16 MiB 镜像以及接入前完整镜像和 NVS 单独备份。恢复前先核验对应目录中的 SHA256SUMS，然后执行：

python -m esptool --chip esp32s3 -p <SERIAL_PORT> \
  write_flash 0x0 /path/to/stackchan-full-16mb.bin

完整镜像会覆盖 NVS。若只需恢复 Wi-Fi/设备设置，应使用已保存的 NVS 分区镜像，并在写入前再次确认偏移和长度。

最终真人验收

  1. 在设备 0.5 至 1 米内自然说 “Davie”，确认进入 listening。
  2. 说一句普通问题，确认 Davie 的文字和语音均正确返回。
  3. 老师声音播放时直接讲话，确认旧音频立即停止且新问题被识别。
  4. 说 “Look at this and explain it”，确认相机内容正确；再追问颜色或物体，确认上下文连续。
  5. 从官方 Launcher 打开 DAVIE，确认入口和原有设置、舞蹈、遥控等官方功能并存。
