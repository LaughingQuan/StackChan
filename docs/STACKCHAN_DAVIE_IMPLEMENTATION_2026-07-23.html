Implementation report · 2026-07-23

Official Stack-chan.
Local Davie.

以官方 1.4.3 开源固件为主体，通过独立 Gateway 接入本地 ASR、Davie、TTS、视觉、硬件动作与可恢复伴读。本文记录已实现内容、真实证据、恢复路径及尚未伪造通过的物理验收项。

最终架构

Stack-chan 设备

保留官方屏幕、表情、舵机、触摸、摄像头、双麦克风、扬声器、配网、OTA、Xiaozhi WebSocket/Opus 与 MCP。

Local Gateway

负责协议转换、端点判断、generation-safe 打断、相机会话绑定、本地设备动作、伴读断点、认证和运行状态，不承载模型权重。

NVIDIA Media

Fun-ASR 处理语音输入，CosyVoice3 处理语音输出。Gateway 只传输标准 WAV/PCM/Opus 数据。

Davie

继续负责人格、记忆、知识库、工具、任务编排和多模态理解；设备通过稳定 session key 与 session id 延续上下文。

  • 生产能力 smoke 发现 5 个模拟官方 MCP 工具，远程音量调用、相机结果回传及两句伴读全部通过；暂停未跳句，恢复后完成，共收到 113 个音频包，测试书籍随后自动卸载。
  • 视觉 E2E 使用真实 JPEG，经 Davie 多模态接口返回与画面一致的具体描述。
  • 实体设备固件已刷写并保留原 NVS；启动日志确认自动进入 AI Agent、Davie 唤醒模型、AEC、摄像头和完整官方 MCP 均已载入。
  • 启动日志确认只注册一个唤醒命令：HELLO DAVIE -> hcLb DdVm。远距离 Mac 扬声器合成语音完成两次独立唤醒与重连，识别概率分别约 0.47 和 0.44，设备均进入 Listening。
  • 唤醒后的真实相机调用已拍到设备上方天花板与矩形灯，并由 Gateway 原子保存 JPEG；同一照片已通过生产 Hermes CLI 发送至 Jason Telegram，消息 ID 为 4371。
  • 生产服务已升级到 0.2.0 并处于 active，持久化目录可写，健康接口正常，未修改无关 Davie/Hermes 服务。
  • Hermes 用户插件测试 26 项通过；生产 Davie 会话 trace 显示延迟工具桥真实执行 stackchan_status，返回 Gateway 0.2.0 正常、设备当前未连接，没有把注册状态冒充物理在线。
诚实边界：远距离合成 “Hello Davie” 已形成两次真实声学触发证据，但一次单独的远距离合成播放仍不稳定；真人在设备旁自然说一次的识别率、真实房间回声与播放中打断仍需最终验收。进入 Listening 后是持续会话，用户应直接说需求，而不是重复唤醒词。离线可预装伴读内容，但远程即时开口、拍照和控制需要当前设备会话已连接。

构建与部署

固件

cp firmware/sdkconfig.defaults.davie.example firmware/sdkconfig.defaults.local
# Edit only local endpoint values. Provision Wi-Fi through the device UI.
source /path/to/esp-idf-v5.5.4/export.sh
cd firmware
python3 fetch_repos.py
idf.py build
idf.py -p <SERIAL_PORT> flash

Gateway

cd integrations/davie-gateway
uv sync --dev
uv run pytest -q
uv build
# Install the wheel on a Linux host and use deploy/stackchan-davie-gateway.service.

Hermes / Davie 插件

cd integrations/hermes-stackchan
python3 -m unittest -v test_plugin.py test_install.py
python3 install.py
hermes plugins enable jm-stackchan
hermes tools enable --platform cli stackchan
hermes tools enable --platform api_server stackchan
hermes tools enable --platform telegram stackchan
hermes tools enable --platform feishu stackchan

安装器只复制独立用户插件并写入 ~/.hermes/stackchan.json；管理员令牌使用单独的 0600 文件，不进入仓库或聊天记录。插件更新后应重启 Gateway，并用会话 trace 验证真实工具调用。

恢复路径

NAS 已保存原厂 1.4.4 完整 16 MiB 镜像以及接入前完整镜像和 NVS 单独备份。恢复前先核验对应目录中的 SHA256SUMS，然后执行：

python -m esptool --chip esp32s3 -p <SERIAL_PORT> \
  write_flash 0x0 /path/to/stackchan-full-16mb.bin

完整镜像会覆盖 NVS。若只需恢复 Wi-Fi/设备设置，应使用已保存的 NVS 分区镜像，并在写入前再次确认偏移和长度。

最终真人验收

  1. 在设备 0.5 至 1 米内自然说 “Hello Davie”，确认一次进入 Listening。
  2. 说一句普通问题，确认 Davie 的文字和语音均正确返回。
  3. 老师声音播放时直接讲话，确认旧音频立即停止且新问题被识别。
  4. 说 “Look at this and explain it”，确认相机内容正确；再追问颜色或物体，确认上下文连续。
  5. 装载一段文章，确认暂停后再继续会重读被打断的当前句，而不是跳到下一句。
  6. 从官方 Launcher 打开 DAVIE，确认入口和原有设置、舞蹈、遥控等官方功能并存。
