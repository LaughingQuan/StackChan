DAVIE DESKTOP BODY · QUICK GUIDE

不用找菜单，
直接叫 Davie。

Stack-chan 是 Davie 的本地耳朵、摄像头、声音、表情和可转动的头。开机联网后，日常操作以语音为主；官方 Launcher 和 Settings 仍然保留。

基本交互

1 · 唤醒“Davie”
看到进入 Listening 后再说完整需求。
2 · 对话“How is the weather today?”
Davie 会延续同一设备会话的上下文与记忆。
3 · 看东西“Davie, what do you see?”
摄像头真正拍照后才进行解释，不会假装看见。
4 · 打断在 Davie 说话时直接讲话。旧语音会被取消，新问题会进入同一上下文。

语音功能表

想做什么可以这样说行为
查看能力Davie, what can you do?本地立即回答，不调用大模型。
看并解释Davie, look at this and explain it.拍照、视觉理解、语音回答。
继续伴读Davie, continue reading.从断点继续；被打断的当前句会重读。
暂停伴读Davie, pause reading.立即暂停并保存进度。
停止伴读Davie, stop reading.停止并把下一次起点重置到开头。
查询进度Davie, where did we stop in the book?说出书名与大致进度。
提醒Davie, remind me in ten minutes to take a break.在设备本地创建提醒。
音量Davie, set the volume to 45.只有设备确认成功后才回答完成。
动作Davie, turn your head left.控制头部向左、右、上或回正。
灯光Davie, set the LED to blue.控制机身 LED 红、绿、蓝、白或关闭。

从 Davie 聊天控制

Telegram、飞书、Hermes Web 和命令行使用同一组 Stack-chan 能力。自然地告诉 Davie 要让机器人做什么即可；Davie 会先检查 Gateway 和当前设备会话，不会把“工具已配置”误报成“机器人已经执行”。

聊天需求示例离线时会怎样
检查连接检查一下 Stack-chan 现在能不能用。仍可返回 Gateway 健康与设备是否已唤醒。
让机器人开口让 Stack-chan 说：“该休息一下了。”明确提示先在设备旁说 “Davie”。
查看面前物体让 Stack-chan 看看面前是什么，不要朗读结果。不伪造画面；提示建立当前设备会话。
预装伴读把这篇 TXT、Markdown 或 HTML 装载到 Stack-chan，先不要播放。可以预装并保留进度，不要求设备在线。
控制设备把 Stack-chan 音量调到 45，头向左转 30 度。不声称动作成功；提示先唤醒。
本地提醒让 Stack-chan 十分钟后提醒我休息。设备本地提醒需要在线；持久任务应改用 Davie 定时任务。
聊天与语音的区别：聊天可以在机器人离线时预装伴读内容和查询 Gateway；即时开口、拍照、音量、头部、LED 与设备本地提醒必须先在 Stack-chan 旁说 “Davie”，让官方固件建立当前会话。

屏幕与菜单

不新增一套重复的复杂菜单。默认进入官方 AI Agent 界面，屏幕会用 Listening、Looking、Reading、Speaking 等状态告诉你当前动作。需要配网、音量、开机行为或其他官方功能时，再回到官方 Launcher 与 Settings。

开机行为：Davie 版本在没有用户偏好时默认进入语音待命。如果你在 Settings 关闭“Start AI Agent on boot”，该明确选择会被保留，不会被固件强制覆盖。

伴读如何使用

书籍或文章由 Davie、Web、Telegram 或其他客户端通过认证 API 装载到 Gateway。内容和句子级进度保存在 Gateway，不依赖 TF 卡，设备重启后仍可继续。TF 卡未来可用于离线书库，但不是当前接入的必要条件。

内容可以在 Stack-chan 空闲或离线时预先装载。需要设备立即开口、拍照或执行硬件动作时，请先叫醒 Davie 建立当前会话；这是官方 1.4.3 的按需连接设计，可减少空闲功耗和无意义长连接。

边界

  • 摄像头是 0.3 MP，适合近距离物体和清晰大字，不适合远处小字或复杂扫描件。
  • 喊出 “Davie” 后应等待 Listening 状态再说需求。
  • 远程立即说话、拍照或控制硬件需要设备处于已连接的 Davie 会话；离线装载的伴读内容会保留。
  • 语音、网络或模型服务不可用时，设备会明确提示，不会假装完成硬件动作。
  • 真人近距离唤醒、房间回声以及播放中打断仍应在实际摆放位置做最终验收。
